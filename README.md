# Glenoid-ID-Test
This software was developed on python to prove the real world feasibility of an idea outlined in the research paper "Glenoid Fossa Probe Proposal using iPhone camera and LiDAR sensor" by William Dorman.

# How To Run: 
1. Download the zipped file in the releases section
2. Extract the file and ensure all relevent dependencies are installed
3. Run the app.py and go to the url: http://localhost:8080 OR find your local machine's public IP and go to http://[YOUR__IP]:8080
4. Allow access to your camera and run the app
